# 交给 Godot AI 的说明

素材已经按组分文件夹：身体、手、齐刘海、双马尾、蓝色眼睛、嘴巴。身体内的素体是身体＋头部合成，不含手和五官。

每张 PNG 对应一个部件、一个动作，透明背景。横向是动画帧，纵向是方向。不要自动裁剪；所有部件按同一画布原点、同一帧号对齐。拾取为40×40，其他为32×32。各动作的方向行、有效帧数和毫秒时长见图集说明.json，不能把睡觉也当成三行。蓝色眼睛的睡觉图是原工程的闭眼帧，不是睁着蓝眼睡觉。

## 层级：从后到前

优先规则：举起的手，正面和侧面必须高于所有部件（头发、五官、发饰也在手下面）；侧面即使名为后手，举起时也必须置顶。背面举手仍在后发下面。拾取动作第4～6帧（从1开始编号）属于举手帧。以下普通顺序仅用于未举手时，不能覆盖这条规则。

- 行走、待机、拾取的正面/侧面：后发 → 后手 → 素体 → 前手 → 蓝色眼睛、嘴巴 → 前发 → 侧发 → 发饰。
- 坐姿正面：前手 → 后发 → 素体 → 蓝色眼睛、嘴巴 → 前发。这里手必须低于后发，不能沿用站立顺序。
- 坐姿侧面：素体 → 前手 → 蓝色眼睛 → 前发 → 双马尾侧发。后手在当前工程关闭，侧面后发没有像素时不显示。
- 背面：后手 → 素体 → 前手 → 后发 → 发饰。前发和五官的背面帧透明，不要拿正面补上。
- 睡觉正面：后发 → 素体 → 前手 → 闭眼、嘴巴 → 前发。

图集内不含额外的后手透明动作文件时，说明该动作没有后手像素。双马尾文件夹同时有后发、坐姿侧发，以及待机发饰，必须保留为不同节点，不能全部合并。发饰在当前工程关闭，作为可选素材提供。手层即使当前隐藏也提供完整图片；是否启用请按层级关系.json 的 enabled 标记，不要全部强行显示。

层级关系.json 给出按用户举手优先规则修正的每个动作、方向、帧的 backToFront（从后到前）顺序，包括 enabled。相同 file 可能对应多个源图层：身体和头部已合成成一个素体文件，运行时该文件只画一次，采用其中最后一个有效位置。普通帧按工程原顺序；举手帧使用上述置顶规则。坐姿侧面第1帧已移除串帧杂线。

请让各 Sprite2D/AnimatedSprite2D 使用同一动画时钟，动画状态统一为动作＋方向。按顺序设置递增 z_index；坐姿正面和背面分别切换，不要依赖节点树的一套固定顺序。纹理用最近邻，关闭自动裁剪。保持当前像素、动画幅度和坐姿五官浮动，不重画、不更换角色。
