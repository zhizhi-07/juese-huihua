# 衣柜多件叠穿修正 · 2026-10-30

## 原因与修改

原实现用「头发 / 衣服」类别作为穿戴记录的唯一键；穿上另一个同类别成品会替换前一个。现在按成品编号记录：同类别可同时穿多件，每件的「试穿」按钮穿上后变为「脱下」，可独立移除。

刷新成品、筛选类别、更新成品不会脱下其他已穿部件；归档只移除对应一件。「脱下全部」仍可一次清空。显示穿戴列表也列出同类别所有已穿部件。

只修改 `js/wardrobe.js`、`index.html`（模块缓存版本）、`README.md` 和 `test/wardrobe-browser.cjs`。保留已有高清图片、位置、导出、ETag 和草稿保护逻辑；不改服务器、真实成品文件或人物像素，不迁移数据，不刷新用户现有页面。

## 实测

先运行原有衣柜单元和浏览器测试，均通过。加入「前发＋独立后发＋衣服同时穿戴」回归测试后，在旧实现上真实失败：实际已穿 2 件，期望 3 件，退出码 1。

修改后以下测试退出码均为 0，原始输出保存在 `test/output/wardrobe-multiwear-verification.log`：

- `node test/wardrobe-browser.cjs`：同类别多件同时穿戴，检查场景实际前发/后发颜色像素；脱下后发仍保留前发和衣服；刷新、筛选和归档仅影响对应部件；脱下全部；既有走动、坐下、拾取、版本冲突、导出、重新打开和草稿隔离继续通过。仅使用隔离服务和合成测试工程。
- `node test/wardrobe.cjs`：独立成品、透明阵列与 JSON 导出。
- `node test/persistence.cjs`：保存和冲突保护。
- `node test/part-export.cjs`：既有部件导出。

## 使用与限制

分别对前发、后发、发饰、衣服点击「试穿」即可组合；不需要合并或重新收录原有成品。同一部位后穿的叠在前面；不会自动判断重叠部件并替换，想换掉旧件需先点其「脱下」。没有增加保存穿搭组合或手动调整遮挡层级。

旧标签页请先保存自己的绘画修改，再刷新加载新版。没有逐件验收用户全部成品的重叠效果。
