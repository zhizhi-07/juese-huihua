# 衣柜后发双层遮挡修正 · 2026-10-30

## 真实对象与原因

用户截图对应来源工程 `character-gold-mix-1793320553623`（人物 · 灰色混搭前80011＋后80009）。已收录的「双马尾」含「头发 / 80009 / 底层后发」和「头发 / 80009 / 侧面后发」两层，未漏收录或合并图层。

问题是试穿 `rank()` 把所有名字以「后发」结尾的图层放在同一个遮挡位置。来源工程中底层后发位于身体后，侧面后发位于头部前、前发后，不能压在身体后面。

修改只涉及编辑器代码和测试：

- `js/wardrobe.js`：区分侧面后发与底层后发。背面仍保持原工程的后发覆盖后脑规则；其余朝向依次为底层后发、身体/头部、侧面后发、前发。
- 同一排序函数对照实际帧读取手部在身体/头部前后的来源顺序，避免坐下和行走时局部手部被错误穿插。
- `index.html`：更新模块缓存版本。
- `test/wardrobe.cjs`：增加双层后发及前后手遮挡断言。
- 新增 `test/wardrobe-rear-order.cjs`：对真实保存素材进行逐帧、逐像素的来源图层顺序对照。

没有修改 `core.js`、绘画分组、人物像素、成品 JSON、成品收录内容或其他工程；没有合并/删除两层后发，也没有刷新用户已有页面。已有成品不需重新收录。
