# 合并改由 Ctrl+E 触发（2026-06-16）

用户要求：界面上不要再写“合并”按钮 / 入口，直接按 Ctrl+E 就是合并。

## 改动
- `js/layer-shortcuts.js`：图层面板头部的「合并图层」按钮已去掉（保留「复制图层」）。
- `js/layer-multiselect.js`：多选操作条里的「合并所选」按钮已去掉（上移 / 下移 / 建组 / 单选保留）；`app.mergeSelectedLayers` 实现保留，只由快捷键调用。
- `js/app.js`：Ctrl+E 统一入口 —— 选了 2 层及以上合并所选，只有当前层时向下合并；Ctrl+Shift+E、Alt 组合仍不触发合并。

## 验证
- `node test/layer-shortcuts-browser.cjs` → PASS（Ctrl+J / Ctrl+E / Ctrl+Z / Ctrl+Y、选区复制、输入框与 contenteditable 守卫、Shift 守卫）。
- `node test/layer-multiselect-browser.cjs` → PASS（连选 / 点选 / 上移 / Ctrl+E 合并两层 / 建组 / 方向键整体移动 / 删除所选 + 撤销），测试里原来的按钮点击已改为按 Ctrl+E。
