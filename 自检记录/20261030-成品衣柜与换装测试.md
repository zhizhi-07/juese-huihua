# 成品衣柜与换装测试 · 2026-10-30

## 已实现

- 顶部新增「成品衣柜 / 换装测试」。原分支仍是草稿区，不自动搬运或认定旧稿完成。
- 展开「标记当前工程的成品」，填写名称、选头发或衣服、勾选这一件成品的部件，然后收录。勾选部件的全部已有动作一并保存。
- 复用原 `/api/projects`、`/api/project` 和 ETag 保存接口。一件成品一个 `data/projects/finished-<UUID>.json`，只含勾选的部件及透明底图，不带原身体、整张源素材或未勾选草稿。
- 成品文件不再混入普通草稿工程下拉列表；在衣柜专门管理。可手动更新、归档，更新前版本不一致则拒绝覆盖，原文件保留 `.bak`。
- 可同时穿一件头发、一件衣服；点击测试场景后，方向键 / WASD 移动、C 坐下或站起、E 拾取。黄色物件需靠近才能实际拾取，按钮也能单独测试动作。右侧可选朝向、动作、脱下和重置。
- 不修改原绘画工程、工具、选层或未保存草稿；关闭/重新打开不强制刷新原页面。
- 单件「一键导出」下载 ZIP：`全部动作.png`、各动作透明阵列 PNG、`阵列说明.json`、干净的 `成品.json`。阵列说明记录位置、尺寸、方向、帧数、时长。成品 JSON 兼容原导入和精灵表导出器。

## 范围与限制

- 仅接入现有 `original32_*` 人物动作。缺动作、方向或当前帧无像素会提示，不用待机图替代；覆盖统计显示实际有像素的帧数，不代表自动审核合格。刻意留空的背面前发也可能显示无像素提示。
- 场景是功能测试场，不是完整游戏；没有做场景编辑、碰撞、保存角色位置或穿戴搭配，也没有生成或补画新服装/发型。
- 试穿采用身体、衣服、头部、前后发和发饰的固定穿插顺序；特殊自定义遮挡关系仍需人工查看。侧向素材用水平镜像提供左右朝向。
- 衣柜默认为空，须用户自己确认成品。没有替用户将现有半成品标为完成。
- 旧标签页若尚无新入口，先保存自己的修改，再手动刷新。未操作或刷新用户现有页面。
