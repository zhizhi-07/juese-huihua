# 网页 AI 绘画

在现有编辑器右上角点击「AI 对话」。默认模型服务为 `http://127.0.0.1:9182`，无须填写密钥。Vibe 助手的 API Worker 需要保持运行。

1. 先保存当前网页中尚未保存的修改，再刷新以加载新功能。
2. 点击「从当前工程开分支」，输入分支名称，在新打开的分支页面继续。
3. 选择模型和绘画类别。头发读取人物规范及发型教程；眼睛读取人物规范及眼睛专用规范；衣服／裙子／鞋子读取人物规范及衣服专用规范。人物其他任务、建筑、物品读取各自规范。每类另加通用工程读写约定，不加载无关类别的专用文档。
4. 在编辑器选中需要修改的可编辑图层，或点击「AI 绘画图层」创建新层。面板遮住图层列表时可先收起面板，选层后再点「AI 对话」。
5. 可点击「参考图片」上传 PNG、JPEG、WebP，或在输入框粘贴截图；最多三张，支持预览和移除。长边超过 1024 像素时会缩小；参考图只保留在当前页面，刷新或新开分支后需要重新添加。
6. 输入要求并发送。AI 会收到当前合成画面、参考图、目标图层在当前素材表各帧的像素及帧结构。只有选中的目标图层可以被修改。
7. 点击「应用 AI 修改」预览。应用后自动把实际渲染画面回传给 AI 检查，包括当前帧和本次修改涉及的帧，最多十二帧；也可点击「检查当前画面」。检查只给出意见，不执行绘画指令。停止检查不会撤销已应用的草稿。
8. 必要时点击「撤销本次修改」。满意后用原来的保存按钮或 Ctrl+S 保存，仍执行版本校验。

## 待机优先与修改位置

人物、眼睛、头发、衣服默认只允许画待机。待机所有方向、所有帧由用户全部确认后，用户明确要求其他动作时，勾选「待机已全部确认，本次明确允许画其他动作」，并在本次文字要求中说明动作。勾选只作用于本次发送，不会永久解锁；AI 自己说通过、保存工程或切换动作都不算授权。前后端都会拦截未授权的非待机像素。

AI 回复会区分「未产生像素修改」「仅生成方案、尚未应用」「已应用到分支草稿」和「已撤销」。旧历史文字会标记为无法证明已绘画。刷新不会保留待应用方案，需要重新生成。

生成方案后会显示工程名、目标图层、动作、帧号、像素坐标范围及目标单层的修改前后对比。点「定位」切到对应帧；应用后自动切到首个修改帧。隐藏或完全透明的目标图层会被提醒先显示，相同像素和透明像素的无效色值变化不算绘画结果。

## 失败重试和原始输出

「重试上次请求」重新发送上一条要求，保留该次参考图和已明确授予的动作范围，不在聊天中重复堆积同一条用户消息。可先切换模型再重试；工程、目标图层、帧或类别发生变化时，会要求按当前画面重新发送，避免套用旧上下文。刷新后只能从历史文字恢复，参考图需重新添加。

「查看模型原始输出」在成功或失败时显示新请求收到的原文、字符数和返回状态，支持复制。格式错误时自动展开。原文只留在当前页面，之前未保留的输出无法补回。面板最多展示 512000 字符，超过会注明截取；不记录请求中的图片数据或其他工程。

长度上限截断、数据流中断、空内容和 JSON 结构错误会区分提示。完整 JSON 前后带说明或代码围栏可以解析，但缺失括号的半截数据不会补全后应用。默认要求优先当前帧、单次不超过 512 个像素，复杂动作逐步生成；生成校验仍保留总像素及权限保护。

AI 回复期间可以继续绘画，但此前生成的结果会在应用时检查版本；旧结果不能覆盖后续修改。对话按工程保存在当前浏览器中，分支创建时会复制当前对话。工程 JSON 继续沿用原存储方式。

当前服务提供 Claude Opus 5.5、GPT-6 等模型，未返回 GPT-6.1；模型选择中将其显示为不可选。以后服务提供该模型时，点击「连接并拉取模型」即可刷新。

限制：每次最多应用 20000 个像素，只修改当前素材表的一个目标图层；复杂发型、多个图层和完整动作请分步处理。此接入不包含联网搜索。

验证：隔离工程中的真实浏览器测试覆盖模型列表、文档路由、像素应用、撤销、草稿冲突阻止和手动保存；原有共享保存回归测试通过。真实 GPT-6 调用携带画面输入，成功返回三个通过校验的绘画像素。未修改用户人物素材或工程 JSON。

图片功能验证：上传、粘贴、移除和图片随请求传递通过浏览器测试；自动检查接收到的渲染图中，采样确认包含刚应用的像素。真实模型正确区分了工程画面的蓝紫色方形和参考图的红色圆形，未在文字中提供这些答案。服务偶发空回复时自动重试一次；检查回复含绘画指令会被拦截。
