# 眼睛补齐全部人物动作

原因：supported 中明确用 part !== 'eyes' 排除了斧头/钓鱼等10个工具动作；setup 遇到已有联动就直接返回，不会补新动作图层。
已修复：眼睛与头发都按当前工程的人物动作识别；再次同步会补缺少的关联层，复用原关联编号和配置，不重新建立/混用其他眼型。背面仍不生成眼睛，隐藏睡觉规则不变。

## 验证
- bug-before.log：旧版在浇水没有关联眼睛处失败，退出1；新版 test/eyes-all-actions.cjs 通过。
- verification.log：全部动作、无自动眨眼、原眼睛、当前头部眼睛、当前头部头发、原头发、面板7项检查退出0，语法0。含新旧关联、10个工具动作精确像素、背面排除、重复同步不增层、撤销/重做、保存重开及原头部不变。
- project-verification.json：GET /api/projects、/api/status 后读取当前素体源，在副本新增临时独立验算眼睛层、同步14套动作，生成154帧，0裁切，包含斧头与4个钓鱼动作。所有原图层像素和动作结构不变；API回读与快照一致，PUT次数0。project-before.json、ETag/SHA256留存。
- 第一次工程副本验算选到了缺待机首帧的旧通用眼睛层，所以没有源稿可生成；改为选择有正/侧首帧的独立眼型后通过。一次命令漏设NODE_PATH造成依赖读取失败，补用已有Temp依赖后继续；未安装新依赖。

## 使用
先保存草稿，再自行重新打开页面加载新版。选中该眼型，点一次“同步全部”补齐旧关联缺少的动作，再开启实时同步。不会自行恢复或新建坐姿方向，不写素体，不覆盖未保存草稿。
未验证用户当前浏览器草稿或所有眼型的视觉贴合；缺方向待机首帧时仍会跳过该方向并提示，不猜画眼睛。
