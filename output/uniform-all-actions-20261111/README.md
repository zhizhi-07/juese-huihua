# 校服裙装九动作算法试稿

仅用已画的正/侧/背三张待机首帧生成156帧（3原首帧+153派生），未逐帧补画。九动作：行走、待机、拾取、浇水、镐、斧头、锄头、镰刀、种植。没有坐姿，不复用旧衣服或旧动作。

## 算法
1. 从各帧body实际像素提取躯干顶、腰部中心与脚底；每动作使用自己的画布。
2. 上衣与裙摆按腰部分段：上衣跟肩腰插值并按身体高度最近邻压缩，裙摆作为独立连片轮廓随腰部移动，不按素体腿间透明区挖洞。
3. 裙摆下沿相对腰部横向滞后最多1个高清像素（半个逻辑像素），静止不额外摆动。
4. 袜子/鞋复用现有ClothingFit.fromIdle的双脚分段，对2×源图的4个像素相位分别映射，不先缩小源图。
5. 衣服插在body后、原来的head/手/工具等层前；原图层相对顺序不变，导出候选仅重映射父层索引。

- 已查看基本动作、浇水/镐/斧头、锄头/镰刀/种植的逐帧接触图。GIF已生成，未在实时播放器中逐个观看，不宣称视觉合格率100%。
- GIF帧时长使用原工程值，拾取末帧为500ms。透明图集编码/解码逐字节回环通过。
- 最终GET与原API快照字节一致；没有PUT、未刷新前台、未修改编辑器源码或衣服按钮。

## 边界和恢复
这是一套校服裙装的算法样例：上衣/裙摆/鞋袜分界来自此三张源稿，不是任意衣服自动分类器。未处理长袖随手臂变形、裤装模式或所有裙型。挤压时按最近邻重排行，不声称每个源细节都在每帧完整可见。
未写工程，因此不需要回滚；不导入候选即可丢弃试验。后续要保存应重新GET最新ETag，不盲传旧整稿。
