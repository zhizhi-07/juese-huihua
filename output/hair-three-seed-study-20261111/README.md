# 三首帧头发算法试验

## 结果
新画栗色短发正/侧/背待机首帧，用三张原图生成九套动作共156帧（含三张保留首帧，即153张派生帧）。原工程未写入，API最终SHA256与ETag均未变化。

## 算法
- 读取各帧head像素包围盒，以水平中心和顶部为锚点；不假设九个动作画布相同。
- 整体位移来自目标帧头部与本方向待机首帧锚点差。
- 复用js/hair-animation.js导出的PE.HairAnimation.deform，不改编辑器源码。
- 只有下方鬓发/背面发梢参与局部形变，头顶和刘海固定；发梢相对头部的纵向滞后取当前与前帧头部高度差，限幅1格。固定轮廓与移动轮廓相邻处沿用现有补点逻辑。
- 头部静止不额外摆；各方向待机首帧逐像素保留。首帧以外参考上一循环帧，减少循环边界跳变。
- 头发放在眼睛之后、原本后续手/工具层之前，不变更原版图层相对顺序。

## 边界
本次是简单短发可行性实验，不代表长发/马尾/卷发通用适配。暂未做水平甩动、角度旋转或额外关键姿态。按帧而非按毫秒计算滞后；变帧率动作需要时间模型。没有给视觉合格率编造百分比。
