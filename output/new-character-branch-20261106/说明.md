## 还可以继续

- 换发色、换裙色只需改 `build.cjs` 里的 `C` 配色表重新生成。
- 想加第二个发型或第二套衣服，复制同样的图层命名（`头发 / <系列名> / 前发`、`服装 / <名字>`）即可在同一分支共存。
- 头发联动（飘动）在编辑器里对 `头发 / 云雾 / 前发` 使用“头发实时同步”即可，后发会自动跟随。
