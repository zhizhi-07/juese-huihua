# 服装动作适配与分区保留规范

2026-11-02 根据用户逐帧手改及说明补充。制作、同步或修正带服装的人物动作前必读；适用于行走、待机、拾取、坐姿、睡觉等已获授权的动作，不只适用于坐姿。阅读本文不等于获准修改服装或扩展动作。

先遵守《后台工程读写约定.md》和《人物绘制AI要求与自检.md》。服装造型按《衣服绘制AI要求与自检.md》；只有贴合衣裤才再读《贴合衣服裤子画法与自检.md》，实际做坐姿才再读《坐姿绘制AI要求与自检.md》。不为一个任务连读无关类别。

## 一句话原则

**分区复制，按姿势调整；阴影跟着对应部位走，不重新设计衣服。鞋是鞋、裙子是裙子、上衣是上衣，不能混在一起缩放或重算颜色。**

## 1. 以用户当前手改稿为准

- 读取当前分配工程的已保存稿，先看同动作、同方向里用户已经修好的帧，再决定需要同步的部分。只有缺少对应动作参考时，才以获准待机稿为起点。
- 用户修过多帧，就逐帧保留这些修正；不能拿第一帧或待机模板重新生成全部帧，盖掉其他帧的小细节。
- 颜色、领口、扣子、缺口、衣摆延伸、描边、鞋型都属于款式，不是动作适配时可随意简化的杂点。看不清用途时先放大核对，不能先擦掉、填平或归并颜色。
- 原样能贴合的区域不动；只有姿势确实变化的部位，才复制、分段移动并局部修接缝。不得用整层缩放、逐行重采样或全身蒙版重涂代替部位适配。

## 2. 先认分区，再找动作锚点

逐帧区分上衣、腰部、裙片或裤腿、鞋子，再定位肩、腰、膝腿和每只脚的末端。看的是人物实际部位，不是画布固定行号。

本次小黄鸭工程 `character-56620e79-ce79-4fd9-b49c-081f7bc57d67` 的用户行走稿是明确实例：

- 下部大多有清楚分区：**脚末端最后一格是白鞋，倒数第二格是裙子，上面的黄色上衣基本没动**，主要按动作贴上去调整姿势和衔接。
- 分别跟随抬起的脚和落地的脚，不能只认整张画布最下面一行。裙子与鞋子不能互相涂色、挤占或合成一条色带。
- 衣服缺口及其向下延伸是连着的形状，必须保留连接、方向与长度关系；不能压成孤立的一个点，也不能涂成普通黄色衣边。
- 这是当前款式的分区示例，不是所有衣服都必须“鞋一行、裙一行”。其他款式、方向和坐姿仍按当前用户稿辨认。

## 3. 根据姿势调整，不为了有变化而重画

- **行走**：上衣和领口没有明显变化就保留；腰以下按真实迈步、交叠和抬脚调整裙摆或裤腿，鞋子各跟各的脚。保留衣摆缺口，不强加额外摆动。
- **拾取**：按躯干的弯曲、前倾、侧移及腰腿关系局部调整衣片；不能只按头的位移移动整件衣服，也不能为了贴合把原有装饰挤成小点。
- **待机、呼吸、睡觉**：依当前动作实际幅度处理肩腰和下摆；接地部分保持原接地关系。原本变化不大的上衣不增加新褶皱、新色阶或大幅起伏。
- **坐姿**：上身贴当前肩腰，裙片按屈膝、搭腿、包臀与接地关系折叠。正面和侧面露出的脚底仍是鞋，背面坐地的块是臀部，不能照搬站姿最后一行鞋条。
- 同方向用同方向的参考，不能拿正面直接挤成侧面。若当前素体局部被擦除、没有足够姿势依据，不擅自恢复身体，也不凭空编造鞋端；说明缺少的依据。

## 4. 仍要看阴影，但先分清阴影属于谁

**阴影是判断姿势、前后和转折的依据，不是自动重配色的指令。**

- 先保留用户当前衣服、裙子和鞋子已经确认的明暗，再随对应衣片、腿或脚移动、局部调整。不能保留形状却把色阶全部重算。
- 贴合裤子可以参考素体两腿的明暗来判断前后、屈伸和交叠，再转成该裤子已有的布料色阶；不能直接复制肤色或强加固定裤缝。
- **裙子比较特殊**：裙片可能跨过两腿、离开腿部轮廓或搭在腿上。看裙片自身的遮挡、折叠和布料转折，不能把素体腿缝直接画成裙褶，也不能用 body 透明度把裙摆机械裁掉。
- 白鞋仍按用户确认的白色画。若用户原稿已有鞋面、鞋底阴影，保留并跟脚移动；原稿没有的灰面，不能仅因素体那只脚是暗面就批量加上，把白鞋改成灰鞋。
- 同一套里白鞋、偏灰的裙片、金黄的衣边可能紧邻，必须分别取样，不能因为接近或都在脚边就统一颜色。阴影只作用于所属分区，不能吞掉缺口、白色下摆或点缀。

## 5. 保存前必须逐项核对

- 对照用户当前稿，原样保留区逐像素不变；确实移动的区按位移比较，非必要处不得变色或丢像素。未改配色时，每个分区的颜色都须来自该分区获准稿。
- 单独显示衣服，逐帧检查白鞋、裙片、上衣分区是否仍分明，缺口和衣摆延伸是否连续，装饰是否保留；不能只看包围盒或合成后大致相似。
- 隐藏头发查看完整衣片，再恢复实际手、五官和头发合成，确认遮挡；只改预览副本显隐，不修改这些部件的原始数据。
- 全部获准方向、全部帧均看原尺寸与放大、浅底与深底，并检查首帧到末帧再回首帧。抬脚时鞋端、衣摆与阴影要跟同一部位，不能各动各的。
- 数据与渲染测试通过，不代表细节正确。必须另查“白鞋有没有被改灰、裙片有没有被染黄、缺口有没有缩成点、上衣有没有被无故重画”。
- 保留帧数、时长、尺寸与未授权层；按版本校验保存并 API 回读。遇到用户新保存必须比较合并，不能强盖。未保存的前台草稿不刷新、不声称已纳入。

## 禁止再犯

整块平移冒充姿势适配；整层缩放压坏领口与缺口；白鞋随素体阴影变灰鞋；裙片与鞋子混色；裙摆按两条裤腿裁切；上衣原本几乎没动却整件重画；用模板覆盖用户逐帧修正。
