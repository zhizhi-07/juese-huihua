# 贴合衣服裤子画法与自检

适用：贴合素体的上衣、睡衣、长裤、短裤及同套鞋子。裙装仍按《衣服绘制AI要求与自检.md》的裙摆、裙褶规则处理；本文件不代替裙装画法。

先读《后台工程读写约定.md》《人物绘制AI要求与自检.md》，服装共用边界见《衣服绘制AI要求与自检.md》。涉及坐姿时再读《坐姿绘制AI要求与自检.md》。只处理分配的工程、部件和已授权动作，不改编辑器程序。

实际制作、同步或修正动作帧前，必须再读《服装动作适配与分区保留规范.md》。本文按素体腿形和明暗处理贴合衣裤的规则，不能机械用于裙片，更不能据此重配白鞋颜色或覆盖用户已修好的细节。

## 一句话原则

**沿着原人物穿衣服：上衣贴肩腰，裤子跟腿形和阴影，两只鞋各跟各的脚。已确认的衣服优先复制、分段移动，不另起一套造型。**

用户本次明确说：“反正就是复制粘贴移动位置”。这指沿用已确认款式，不是把一张站姿衣服整层平移到所有动作，也不是拿正面衣服当侧面。

## 1. 和裙子哪里一样，哪里不一样

| 项目 | 共通原则 | 贴合上衣、裤子 | 裙装 |
|---|---|---|---|
| 上身 | 先定位肩、颈、胸腹、腰，贴合当前身体 | 按款式保留领口、前襟、衣片和侧片 | 连衣裙上身也要贴合肩腰 |
| 下身轮廓 | 跟着实际姿势，不是一块矩形 | 两条裤腿分别包住对应的腿，不凭空加宽、加长 | 裙片可离开腿的轮廓，按款式从腰向下展开 |
| 下身阴影 | 随对应部位运动，不能留在屏幕固定位置 | 主要说明前后腿、交叠和屈伸，先看素体腿部明暗 | 主要说明衣片转折、裙褶与层叠，不能直接拿腿缝当裙褶 |
| 中线 | 不强加一条贯穿到底的线 | 中立姿态按真实裆部位置；迈步时可斜、可短、可没有 | 不需要画成两条裤腿，裙褶按裙片设计 |
| 运动 | 保留原动作和接地关系 | 上衣、腰、左右裤腿、鞋子按各自锚点跟随 | 肩腰跟身体，裙摆按形态连接，不直接跟某一条腿跑 |
| 手与鞋 | 部件独立，遮挡正确，不动素体像素 | 不因画上衣顺手画手；每只鞋分别核对 | 不用裙摆或裤片盖掉本该可见的鞋底 |

## 2. 开始前先看真实工程

1. GET 当前分支，备份原始响应、SHA256 和 ETag；用户在网页里未保存的内容不等于后台已取得。
2. 按素材表名称确认动作、方向、帧数和尺寸。不要把某次的表索引、32×32 坐标当永久模板，也不要缩放原人物来适配衣服。
3. 逐帧看 body、head、hand、hand 2 和当前服装：标出肩、腰、左右腿、每只脚的末端，以及头发遮住的后领。
4. 用户手改的帧就是这次的造型依据，先保留，再同步其他帧。不要拿旧备份或默认素材覆盖它们。
5. 新衣服仍先画待机，全部方向和帧经用户确认后，只有得到其他动作授权才扩展。

## 3. 上衣：贴身体，但不要顺手画手

- 上衣从实际肩胸开始，领口、腰线、下摆跟对应身体位置；不要只根据头顶或 body 层最高的一个杂点确定肩部。
- 正面、侧面、背面各有自己的衣片关系。侧面的领口、前襟和侧片要说明朝向，不能原样贴正面；背面不画正面前襟。
- 领口是否露肤由款式决定。该露的领口保留，该被后领包住的位置不能在呼吸后突然漏一行皮肤。
- 本次睡衣不需要画手部，不给手层上色，也不把袖子伸进手部区域来“补衣服”。其他衣服若明确需要袖子，袖子仍画在服装层，按现有手腕和遮挡衔接，不能重画手。
- 近手按原关系位于衣服前，远手按原关系留在后；不要为了衣服方便，把所有手统一提到最前。
- 被手或头发挡住的衣片仍要完整。不要靠遮挡藏缺口，也不要照着手的像素给衣服挖空。

## 4. 裤子：腿是靠阴影表现的，不是靠两条竖线

先把衣服隐藏，看清原来两条腿怎么分，再把这种关系带到裤子上。

- **原素体用亮面和暗面区分前后腿时，裤子也用对应的布料亮暗区分。** 复制的是形状、交叠和明暗关系，不是继续用肤色，也不是给每条腿重新套一圈描边。
- 两脚并排时，分界应对准人物真实的裆部/两腿交界，不能按画布正中猜，也不能用偏向一侧的前襟线贯穿裤腿。
- 迈步、交叉、抬腿时，分界跟腿势走：可以斜着、缩短、被遮住，或者不出现独立中线。原稿只有阴影，就不要额外补一条硬线。
- 不把两条固定竖条当成裤腿；不把站姿中线贴到所有行走、拾取帧；不把侧面裤腿画成正面左右对称两块。
- 轮廓和阴影都应跟着同一条腿移动。不能脚位变了，阴影还留在旧位置。
- 素体轮廓能作为贴合裤子的依据，但不要机械覆盖所有 body 非透明像素：先排除不属于衣物的部位和零星像素，识别真实腿形。

## 5. 鞋子：亮侧、阴影侧都要检查

**阴影那块也可能是另一只脚，不是整块都属于裤腿。不能只给亮侧脚画鞋。**

1. 每帧分别找到两条腿的末端，再确定各自的鞋底位置；本该可见的两只鞋都要画，不能凭整个人物的最下面一行推断。
2. 抬起的脚可能比落地脚高，鞋子也随它抬起；不能只沿画布底边涂一条鞋。待机接地脚不漂，行走和拾取中的抬脚按实际动作移动。
3. 普通鞋按已确认造型控制厚度，不擅自加厚鞋面；阴影侧鞋底可以比亮侧略暗，但仍应看得出它也是鞋，而不是漏画。
4. 保留原有轮廓、前后遮挡和透视。被完全挡住的鞋不凭空添出来，也不能为了凑两只鞋把后脚拉出来。
5. 鞋子与对应服装放在同一个套装层，一起选用、隐藏、导出。不能把鞋底画进前发、后发、手或身体层。
6. 发现用户误把鞋底画在头发层时，先识别确切的鞋底笔迹；若需修正归层，只迁移已核实的鞋底像素并保留合成效果，不借机改发型。不能批量擦掉头发下方像素。

### 坐姿不能照搬站姿末行

- 正面下方并排的两块是朝向观看者的脚底板，侧面前伸末端也是脚底板，应按已确认坐姿画。
- 背面最下方的坐地块是臀部，不是两只鞋，不能涂成一条鞋边。
- 裤子跟随坐姿的屈膝、腿面和臀胯，不直接搬站姿裤缝、鞋底位置。

## 6. 装饰和阴影要同时保留

- 小点、雪花、口袋、滚边属于款式。调整裤腿阴影时不能把装饰一起刷没。
- 先确认衣片、腿形和明暗，再把已确认装饰放回对应衣片；不要恢复装饰时顺带恢复已被否决的裤缝。
- 装饰跟随所在衣片或裤腿移动，不固定在屏幕坐标上；跨过轮廓、脚底或手部时应按实际遮挡处理，不往外描。
- 一次只改用户指出的部分。修鞋不顺手重设计上衣，修腿部明暗不顺手删点缀。

## 7. 同步其他动作：复制、移动，少改造型

1. 从当前工程中用户已确认的同方向服装取样；保留配色、领口、点缀和鞋子，不重新发明款式。
2. 能原样复制移动就原样复制。只在真实姿势变化处，按上衣、腰、左右裤腿和鞋子分段定位、衔接，不加无关摆动和新细节。
3. 待机按实际肩腰呼吸连接，脚底稳定；行走跟随左右腿和阴影；拾取跟随躯干变化和每只脚的位置；坐姿按脚底/臀部关系；睡觉按现有姿势适配，不擅改原动作。
4. 正、侧、背各用自己的已确认造型，不能拿正面替代侧面，也不能因头发遮住就省略背面衣片。
5. 循环按实际帧数检查 `首帧→…→末帧→首帧`。颜色、点缀、阴影、鞋子都要连贯，不能只看第一帧。
6. 遇到“少一只鞋”“裤缝位置错”等共性错误，检查所有已授权动作是否有同类问题；不要只修用户截图那一张。

## 8. 交付前自检清单

- [ ] 全部受影响动作、方向、帧都实际打开看过，包含浅底、深底、原尺寸与放大图；合成图确有主体，不是空白图相等。
- [ ] 正侧背款式对应，侧面不是正面贴图；后领各呼吸帧不意外露肤。
- [ ] 裤腿跟原腿形、明暗和遮挡走，没有固定竖条；中线该在中间、该斜或该无时都正确。
- [ ] 两条腿各自的鞋端已核对，阴影脚和抬起脚没漏；没有把坐姿臀部当鞋。
- [ ] 点缀没有因修阴影丢失，也没有因恢复点缀带回错误裤缝。
- [ ] 服装、鞋和装饰归层正确。只显示衣服、隐藏头发时，鞋底不会消失；手与头发的实际像素未被改动。
- [ ] 用户已确认且不在本次修改范围内的帧逐层逐像素不变；其他动作、尺寸、时长、显隐和锁定不变；若改层序，parent 和选层索引已正确同步。
- [ ] 主画布、动画预览与透明 PNG 导出一致。离屏测试不写成浏览器实测。
- [ ] 提交使用当前 ETag，遇冲突先比较合并，不强盖。实际 API 回读一致，备份和本次验证记录可查，不强刷用户未保存页面。

## 9. 本次睡衣已经踩过的坑，不要再犯

侧面穿正面衣服；衣服画进手部；后领呼吸时漏皮肤；所有帧硬套竖直裤缝；只画亮侧一只鞋；抬脚还在画布底边找鞋；修阴影刷掉白点；装饰回来了但错裤缝也回来了；鞋底误落前发层；坐姿臀部被当成鞋。

以上是 2026-10-30 灰色混搭人物睡衣任务的经验。具体颜色、坐标、帧数与层索引都不是通用模板，后续以当前工程和用户最新修改为准。
