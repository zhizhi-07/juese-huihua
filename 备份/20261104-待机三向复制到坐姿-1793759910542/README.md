# 16×16 像素工作台

运行 `启动编辑器.cmd`，打开 http://localhost:8765/index.html 。

当前主工程只保留干净素体：行走、待机、拾取、坐姿；无旧头发、衣服、成品和测试工程。

- 行走、待机使用原生16规格备份。
- 拾取使用原生像素，20×20画布保留伸手范围。
- 坐姿使用用户后画的32规格坐姿，所有画布、坐标与图层统一缩小50%；不裁切、不补画、不移位。各方向画布为14×17、16×17、18×17。
- 主肤色 #FEEDE1，阴影 #E0C5B4，描边 #46465E。
- “重新载入16×16素体”只载入新的干净模板，不恢复旧32规格素材。
- 手动保存：Ctrl+S；后台保存方式见 `后台工程读写约定.md`。

旧工程、旧规范与本次变更前的文件均保存在 `备份/20261104-16x16干净重启/`。旧规范不再自动读取，新的绘画文档由用户重新制定。
