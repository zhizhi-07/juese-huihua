# 画笔 / 橡皮大小调整 · 2026-11-02

## 本次完成

- 画布上方常驻「画笔 / 橡皮」滑条和数字输入，不再藏在可折叠、可浮动的颜色面板。
- 大小统一为 1–128px，滑条、数字和 `[` / `]` 快捷键同步，非法数值安全归一。
- 沿用原来的方形笔刷、撤销栈和高清编辑会话：普通画布按画布像素，高清图层按源像素，放置尺寸不变。
- 画笔和橡皮共用当前大小。没有增加笔刷形状、压力、独立大小记忆或其他功能。
- 只修改 index.html、js/app.js、js/tools.js、js/studio.js、css/workspace-layout.css；新增独立测试 test/brush-size-browser.cjs。
- 保留了任务开始前已有的其他修改；没有写入任何 data 工程文件，没有刷新或关闭用户页面。
