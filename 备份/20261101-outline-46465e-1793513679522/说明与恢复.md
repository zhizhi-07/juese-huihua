## 工件
- before.json：原始 API 原稿；source.json：原始 ETag 与 SHA256。
- candidate.json：修改稿；after-api.json：保存后 API 回读。
- verification.json：逐图层帧差异与验证；save-response.txt：实际保存状态。

## 恢复
先 GET 同一 API 并取得当前 ETag；仅在工程仍与 after-api.json 完全一致时，可将 before.json 作为请求体，带 X-Pixel-Editor: 1、Content-Type: application/json、If-Match: 当前 ETag 执行 PUT，随后回读比较。若用户已有后续修改，不得整稿覆盖：按 verification.json 的 li/key 只恢复相关帧，并逐帧确认仍等于 candidate.json 后再合并保存。
