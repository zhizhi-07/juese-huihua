# 导入灰色去色修改记录

范围：仅 js/pixel-import.js、test/image-import.cjs、test/image-import-browser.cjs；没有读写人物工程、修改人物头发或刷新用户页面。保留原有未提交修改。

行为：原版固定映射到 119 / 178 / 209，且会阈值化透明度；新版对非全透明像素使用 round(0.2126R + 0.7152G + 0.0722B) 转灰，不限制三色，不重判描边，alpha 不变。沿用 hair-gray 接口值。去色依然发生在既有裁选、缩放、可选抠色之后，不恢复被缩小采样或抠色移除的信息。高清保留原图模式仍保持原图，不启用去色。

实测：原版 image-import 测试通过。修改后语法检查 3 项、image-import / image-edit / hd-image-layers 测试全部通过，退出码均为 0。新增检查覆盖 256 灰阶与 alpha、彩色半透明、同色不同位置、32 档阴影不受 colors:8 限制及源图不变。浏览器测试期望已更新并通过语法检查，但未运行浏览器测试。

运行环境：PowerShell；NODE_PATH=C:\Users\Administrator\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules。
初次未设置 NODE_PATH 时报 MODULE_NOT_FOUND（@napi-rs/canvas），改用已安装运行库后测试通过，未安装依赖。
命令及退出码见原版测试.log、修改后测试.log；差异见本次修改.diff；修改前后哈希见两个 SHA256 JSON。原始备份逐一 SHA256 回验通过。

恢复：先确认这三个文件没有后续新改动，再用本目录 js_pixel-import.js、test_image-import.cjs、test_image-import-browser.cjs 分别覆盖回原路径。仅恢复这三个文件，不使用 git reset，也不要恢复 data 文件。恢复前先备份后续修改。

前台：未操作用户页面；使用新选项需先保存未保存工程，再自行刷新并重新上传/裁选原图。已导入的旧三色图不会自动恢复阴影。
