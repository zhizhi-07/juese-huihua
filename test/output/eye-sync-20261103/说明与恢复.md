# 眼睛共用同步规则 / 移除睡觉入口（2026-11-03）

## 本次完成
- 待机的眼睛独立层可用原有「实时同步 / 同步全部 / 编辑基准」。各方向分别取待机第1帧，读取头部标定偏移，跨待机、行走、拾取、坐姿更新；不套用头发飘动。
- 首次关联时，把已有像素与对应方向基准按头部偏移对齐比较。有差异的帧保守设为「保留原画」，包含眨眼及其他特殊画法；不是自动语义识别眨眼。可在「偏移 / 保留帧」取消勾选参与同步，或勾选后独立绘制。
- 沿用既有保存字段 hairAnimation / hairAnimationId，眼睛增加 part: eyes 和 preserved 地址列表；不另建保存体系。旧头发存档兼容，既有头发飘动测试通过。
- 隐藏 sleep / original32_sleep 的动作列表、批量复制和测试动作入口；内置角色不再创建睡觉动作，家具测试不再触发睡觉。旧存档的睡觉表、图层、帧和像素全部保留，不重排编号；现有同步配方也不再写睡觉像素。
- 本次没有读取、保存或重画用户人物工程，没有刷新用户浏览器/覆盖前台草稿。仅编辑器代码与自动测试发生变化。

## 使用
先保存当前草稿，再刷新编辑器。在待机选择未锁定、未分组的眼睛独立层，点「同步全部」或开启「眼睛实时同步」。修改各方向待机第1帧，其他参与同步的帧按头部偏移生成。原有特殊帧是否参与，由「保留原画」控制。缺少方向基准时，不擦除已有眼睛。
