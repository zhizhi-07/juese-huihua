# Ctrl+J / Ctrl+E

## 完成范围

- Ctrl+J：无选区时复制完整图层（所有帧）到上方；有选区时仅复制当前帧、当前图层的选区到新图层，保留原图。支持矩形、选区掩膜及高清源像素。
- Ctrl+E：当前图层向下合并到同组相邻图层，两层全部动作与帧一起处理。两层透明度烘焙进像素；高清图像不会直接压回基础像素网格。合并本身是栅格化，不承诺任意不同像素网格合并后仍可分离原始源图。
- 使用现有 FrameEditing.record 记录一步撤销/重做、刷新图层和标记未保存；不另建历史系统。
- 保留底稿、手部参考层、锁定帧/区域保护。隐藏层、不同素材表、跨层穿插、背面特殊层序冲突、过大合成会拒绝，不部分修改。
- 没有实现图层组复制/合并、多选图层合并、Ctrl+Shift+E 合并可见图层。输入框与可编辑文本中不触发；长按不会连续重复。
- 修改 js/layer-shortcuts.js、js/app.js、index.html 的缓存版本及 README.md；新增两份测试。没有调用工程保存接口，也未改 data 内的工程。
