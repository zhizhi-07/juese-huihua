# 图层缩放方式切换 · 2026-11-01

## 使用

先保存当前网页中未保存的草稿，再自行刷新以加载新版脚本。未刷新、关闭或操作用户现有网页。

画布上方「图像工具」→「缩放方式」：

- **普通像素缩放**：最近邻重采样，实际改变像素数量，不混色。缩小会丢失细节；切换到高清不能找回已丢失的细节，需撤销。
- **高清无损缩放**：保留本次缩放前的源像素，仅修改放置尺寸。
- 自定义「图层宽度」、右下角拖动缩放、「放大图片 / 缩小图片」共用同一个模式。
- 切换选项本身不改图。模式为当前页面的工具设置，不写入工程；尚未手动选择时按当前图层类型显示普通或高清，保持旧工程兼容。
- 高清缩放整层操作；高清局部选区缩放仍被拒绝，避免丢掉未选区域。移出画布的内容仍保留，不裁掉。
