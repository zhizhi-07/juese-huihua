# 跨动作头发复制修复

## 本次范围
只修改编辑器复制功能、脚本版本号、对应 API 文档与测试；没有读取或改写任何人物工程 JSON，也没有刷新用户页面。

## 原因与改动
- 待机、坐姿属于不同素材表。原批量窗口只枚举源素材表朝向；跨动作粘贴使用自动选中的目标图层，可能选中身体或仍引用旧素材表图层。
- 跨素材表省略目标图层时匹配唯一同名图层，不存在则新建独立副本；明确指定的图层仍遵守锁定与底稿保护。
- 新建层使用现有部件排序方法，前发/后发保持对应层序；预览不写入，整批验证失败不改任何目标；像素与新建图层一起撤销/重做。
- 批量窗口增加“目标动作”，保留原朝向与帧范围选择。
- 更新 index.html 的 frame-tools.js 版本号，让用户保存草稿并刷新后加载新功能。

## 复现及验证
修复前运行 `node test/cross-action-copy.cjs`，退出 1：
`AssertionError [ERR_ASSERTION]: 请选择属于目标素材表的具体图层`。
同一回归用例在修复后通过。最终 7 组测试的实际命令、原始输出、退出状态见 verification.log；测试代码 SHA256 见 tested-sha256.json。
浏览器测试使用独立内存工程和临时 HTTP 服务，不操作用户标签页。验证了 Ctrl+C/V、按钮、批量选择待机/坐姿、底稿保护、撤销与重做。截图 verified.png 是测试像素，不是用户真实头发。

## 使用
先保存当前草稿，再刷新页面加载功能。
选中正面头发图层 Ctrl+C，切换待机或坐姿及目标朝向/帧后 Ctrl+V。
一次复制多帧：辅助工具 → 图像工具 → 批量复制… → 目标动作 → 目标朝向 → 全部帧或指定范围。
前发、后发为分层时分别复制。默认叠加会保留目标其他像素；覆盖模式会包含透明像素一起覆盖。原位置复制，不自动适配坐姿头部位置，必要时自行移动。
