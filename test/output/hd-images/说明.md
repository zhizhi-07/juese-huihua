# 高清图片图层：完成与验证（2026-10-30）

## 怎么用
1. 先保存所有旧标签页里的草稿，再刷新编辑器以载入新版。没有自动刷新或覆盖你的页面。
2. “上传图片”→勾选“高清图片图层（保留原图，无损缩放）”。
3. 裁选后填写“放置宽度”（画布单位）。例如原始贴图32×16像素，放在画布上占8×4单位；存储的源图仍是32×16。
4. 放到当前画布，或新建独立素材。移动、右下角手柄、缩小/放大按钮和画布上方“高清放置宽度”仅改摆放参数；缩小再放大不会重新采样源图。
5. 高清图层支持整图翻转、按颜色抠图、撤销/重做、整张复制/剪切/跨帧粘贴、整帧复制；保护区域和锁定仍生效。普通像素图层保持原来的绘画与选区逻辑。

## 存储与导出
- 源RGBA仍放在图层frameData；新增placement={x,y,w,h}，把原始贴图像素尺寸和逻辑摆放范围分开。PNG编码的原图数据及placement一起存入工程JSON，重开后恢复。
- 普通PNG导出在有可见高清层时，按该素材表需要的整数倍率统一提高分辨率；不会先压成逻辑小图再放大。例如测试32×32逻辑画布导出128×128 PNG。部件包、整包和衣柜阵列相应记录pixelScale/逻辑尺寸。
- 普通像素层和没有高清层的旧工程不增加导出倍率。PNG只是一张合并图，要继续无损改摆放尺寸请保留工程JSON。
- 待机画布扩边只平移高清图层的placement，不重编码源图；可能裁掉图片时拒绝整个扩边调整。

## 限制与注意
- 高清图片保持独立贴图；不允许铅笔/橡皮/填充直接往高清层的逻辑像素格写入。请另建像素图层叠加绘画。高清局部选区翻转/抠图/复制暂不自动栅格化，须整张图片操作。
- 摆放按整数画布单位对齐。原始裁选区域最大1600万像素；合成/导出超过1600万像素会提示拒绝，不会静默降低分辨率。
- 逻辑分辨率的像素读取、检查与洋葱皮仍是逻辑网格视图；主画布、动画/帧预览、JSON与用户PNG导出已支持高清。
- 这不是Fashion Sense内容包导出器，未做FS打包或游戏内兼容测试。
- 含高清数据的新工程不要再用未刷新、不了解placement的旧页面保存。先保存并刷新所有要继续使用的标签页。
